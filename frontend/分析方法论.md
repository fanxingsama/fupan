# 短线交易指标分析方法论

> 本文档详细记录平台中所有计算指标的定义、算法、阈值依据和使用场景，供人工审核和调优。
> 对应代码文件：`frontend/src/utils/indicators.js`

---

## 1. 封板率 (Seal Rate)

### 定义
衡量当日涨停板成功封住的比例，反映市场资金做多的一致性程度。

### 算法
```
封板率 = 封板成功数 / (封板成功数 + 炸板数) × 100%

其中：
- 封板成功数 = limitUpToday.length + firstLimitToday.length
  （连板票 + 首板票，这些都是收盘时仍在涨停的股票）
- 炸板数 = brokenLimitToday.length
  （盘中触及涨停但未能封住的股票）
```

### 阈值参考
| 封板率区间 | 含义 | 操作建议 |
|-----------|------|---------|
| ≥ 80% | 强一致性，资金做多意愿极强 | 积极参与 |
| 65%-80% | 正常水平，有一定分歧 | 正常操作 |
| 50%-65% | 分歧较大，追高有风险 | 降低仓位 |
| < 50% | 弱势格局，追涨停大概率吃面 | 以观望为主 |

### 局限性 & 需人工确认的问题
1. **封板成功数的统计口径**：当前将 `limitUpToday`（连板票）和 `firstLimitToday`（首板票）直接相加。但 `limitUpToday` 中可能包含一字板（开盘即涨停且全天未打开），这些票的"封板"含义和正常竞价涨停不同。如果一字板过多可能导致封板率虚高。
2. **炸板数据完整性**：`brokenLimitToday` 来自东方财富的"炸板概股池"，是否能覆盖所有盘中打板的票需要验证。
3. **ST股/北交所的影响**：5%涨停的ST股和北交所30%涨跌幅的票如果混入统计，会影响准确性。

## 2. 涨跌停比 (Limit Up/Down Ratio)

### 定义
涨停家数与跌停家数的比值，反映多空力量对比。

### 算法
```
涨停总数 = limitUpToday.length + firstLimitToday.length
跌停总数 = limitDownToday.length

涨跌停比 = 涨停总数 / 跌停总数
```
当跌停数为0时，直接返回涨停总数（视为极强）。

### 阈值参考
| 比值 | 含义 |
|------|------|
| ≥ 5:1 | 多方碾压，强势格局 |
| 3:1 ~ 5:1 | 多方占优，正常偏强 |
| 2:1 ~ 3:1 | 多空均衡 |
| < 2:1 | 空方占优，弱势 |
| < 1:1 | 跌停多于涨停，恐慌 |

### 局限性
1. 跌停数包含了 ST 股的 5% 跌停和主板的 10% 跌停，比值可能被 ST 集体跌停拉低，但实际不影响短线可投资标的。可以考虑后续过滤 ST。

## 3. 赚钱效应指标组

### 3.1 昨日涨停溢价率 (Yesterday Limit Premium)

#### 定义
昨日收盘时处于涨停板的股票，今日实际涨跌幅的算术平均值。正值说明"打板有肉吃"，负值说明"追涨停亏钱"。

#### 算法
```
溢价率 = Σ(limitUpYesterdayFeedback[i].changePercent) / N

其中 N = limitUpYesterdayFeedback 中涨幅非空的股票数
```

#### 阈值参考
| 溢价率 | 含义 |
|--------|------|
| ≥ +3% | 赚钱效应极好，打板后大概率吃肉 |
| +1% ~ +3% | 赚钱效应良好 |
| 0% ~ +1% | 中性 |
| -1% ~ 0% | 微弱亏钱效应 |
| < -2% | 亏钱效应明显，短线需谨慎 |

#### 数据源质量问题
- `limitUpYesterdayFeedback` 是由 AKShare 的 `stock_zt_pool_previous_em` 接口获取的"昨日涨停股今日表现"。需确认该接口是否包含所有昨日涨停股（含首板和连板），还是仅包含部分。
- 建议对比当日的 `limitUpToday + firstLimitToday` 总数与次日 `limitUpYesterdayFeedback` 的条数，检查是否有遗漏。

### 3.2 昨日涨停上涨占比 (Win Rate)

#### 算法
```
上涨占比 = 昨日涨停今日涨幅>0的股票数 / limitUpYesterdayFeedback.length × 100%
```

#### 含义
如果50%以上的昨日涨停票今天还在涨，说明市场情绪延续性好。如果低于30%，说明隔日严重无人接力。

### 3.3 昨日炸板次日表现 (Broken Board Next Day)

#### 算法
```
炸板表现 = Σ(brokenLimitYesterdayFeedback[i].changePercent) / N
```

#### 含义
衡量"追了没封住的票第二天有没有机会跑"。如果均为负，说明炸板后惩罚力度大，需要更严格的止损。

## 4. 连板梯队 (Board Ladder)

### 定义
将当日所有涨停股按连板高度分层统计数量，形成"金字塔"结构。

### 算法
```
1. 首板数量 = firstLimitToday.length
2. 遍历 limitUpToday，按 boardHeight 分组计数（仅保留 ≥ 2板）
3. 按 height 升序排列：[{height:1, count:45}, {height:2, count:12}, {height:3, count:5}, ...]
```

### 分析要点
- **梯队连续性**：理想情况是每一层都有股票，如 5板→4板→3板→2板→首板 依次递减。如果出现"断层"（如有 5板但没有 3板、4板），说明梯队不健康，可能依靠个别妖股支撑。
- **首板数量**：首板是市场新增做多力量的来源，如果首板数量持续减少，说明增量资金不足。
- **最高板**：反映市场赚钱效应的天花板高度。

### 当前实现的局限性
- 仅统计了数量，未区分一字板和竞价涨停。一字板过多可能虚增梯队繁荣度。
- 未标注断层位置，后续可加入"梯队断裂预警"。

## 5. 情绪周期 (Emotion Phase)

### 定义
根据多个情绪指标的组合状态，将当前市场划分为六个阶段。

### 六大阶段定义

| 阶段 | 典型特征 | 操作策略 |
|------|---------|---------|
| **冰点期** | 封板率<55%, 涨停<30家, 最高板≤3 | 等待，不操作 |
| **修复期** | 从冰点回升，高度开始抬升，涨停数恢复到25+ | 轻仓试错低位首板 |
| **发酵期** | 连板高度上升中，封板率≥60% | 参与主线，追龙头 |
| **高潮期** | 封板率≥75%, 涨停≥50, 最高板≥5 | 持股不追高，注意见顶 |
| **分歧期** | 高度开始回落但仍≥3 | 只做确定性最高的票 |
| **退潮期** | 高度下降+封板率下降 | 清仓观望 |

### 算法（当前实现）

```
输入：最近5个交易日的 trendReports
提取：sealRates[], heights[], limitTotals[]

判定规则（优先级从高到低）：

1. 冰点期: lastSealRate < 55% AND lastLimitTotal < 30 AND lastHeight ≤ 3
2. 退潮期: heights 下降趋势 AND lastSealRate < 55%
3. 分歧期: height 较前一日下降 AND lastHeight ≥ 3
4. 高潮期: lastSealRate ≥ 75% AND lastLimitTotal ≥ 50 AND lastHeight ≥ 5
5. 发酵期: heights 上升趋势 AND lastSealRate ≥ 60%
6. 修复期: height 未下降 AND lastLimitTotal ≥ 25 AND avgSealRate ≥ 55%
7. 默认: sealRate ≥ 60% → 发酵期，否则 → 退潮期
```

### 重大局限性（需人工审核）

1. **规则硬编码阈值**：所有阈值（55%、30、75%等）都是基于经验设定的，不同行情周期下可能需要调整。建议积累3个月以上数据后，回测验证阈值合理性。

2. **缺乏过渡状态**：实际行情中情绪周期的转换是渐进的，不是突变。当前算法可能出现"昨天高潮今天冰点"的跳跃，需要加入平滑处理。

3. **仅依赖量化指标**：未考虑消息面（政策利好/利空）、大盘指数走势、外围市场影响等基本面因素。量化指标只能反映滞后的市场情绪。

4. **数据窗口太短**：使用最近5个交易日的数据，对于判断"大周期"（如月级别的牛熊转换）不够。

5. **判定优先级问题**：规则的优先级排列会直接影响判定结果。例如"高度下降但封板率很高"同时满足分歧期和高潮期条件时，当前代码优先判定为分歧期，但也可能应该判定为高潮分歧。

### 改进思路
1. 引入加权评分制：对 封板率、高度变化、涨停数、溢价率 分别打分（如0-100），然后用权重计算总分，再根据总分区间判定阶段。
2. 引入连续性约束：要求连续2天满足条件才切换阶段，避免单日波动造成误判。
3. 结合大盘指数：如果沪指大跌>2%，直接增加"恐慌"权重。

## 6. 风险预警信号

### 当前实现的 5 类信号

| 信号 | 条件 | 级别 |
|------|------|------|
| 封板率过低 | < 50% | danger |
| 封板率偏低 | 50%-65% | warning |
| 封板率良好 | ≥ 80% | safe |
| 涨停数过少 | < 20 | danger |
| 涨停数偏少 | 20-35 | warning |
| 涨停数较多 | ≥ 60 | safe |
| 溢价为负 | < -2% | danger |
| 溢价偏弱 | -2% ~ 0% | warning |
| 溢价良好 | ≥ +2% | safe |
| 涨跌停比失衡 | < 2:1 | danger |
| 涨跌停比强势 | ≥ 5:1 | safe |
| 最高板断裂 | 前一日最高板-今日最高板≥2 且前日≥4板 | danger |

### 局限性
- 信号之间可能矛盾（如封板率高但溢价为负），当前未做矛盾处理
- 阈值需要随市场风格变化调整（牛市和熊市的"正常"封板率差异很大）

## 7. 趋势图表说明

### 7.1 封板率+涨停数双线图
- 左 Y 轴：封板率（%）
- 右 Y 轴：涨停数（家）
- 用途：观察两个指标是否共振（封板率↑+涨停数↑=情绪回暖）

### 7.2 炸板数趋势
- 炸板数突增是"分歧加剧"的前兆
- 需关注炸板数与涨停数的比例变化

### 7.3 昨涨停溢价趋势
- 连续3天正溢价 = 赚钱效应持续，情绪向好
- 连续2天负溢价 = 需要警惕情绪退潮

## 8. 表格增强列说明

### 已展示但此前隐藏的数据字段

| 字段 | 适用表格 | 分析意义 |
|------|---------|---------|
| 封板时间 (extraTag) | 连板/首板 | 09:30封板=一致性强，尾盘封板=资金犹豫 |
| 封板金额 (sealAmount) | 连板/首板 | 封板金额>流通市值5%=强封，<1%=弱封 |
| 换手率 (turnoverRate) | 全部 | 低换手涨停=锁仓型（筹码集中），高换手=分歧型 |
| 振幅 (amplitude) | 炸板/首板 | 振幅大=分歧大；炸板票振幅>15%说明多空激烈交锋 |
| 竞价涨幅 (auctionChangePercent) | 连板/首板 | 竞价高开>5%=资金抢筹，但也有冲高回落风险 |

### 封板时间的解读
```
09:25-09:35 → 一字板或集合竞价即封板，极度一致
09:35-10:00 → 早盘封板，短线关注度高
10:00-11:30 → 上午封板，正常
13:00-14:30 → 午后封板，观望资金下午进场
14:30-15:00 → 尾盘封板，次日溢价不确定性大
```

## 10. 阈值调优建议

所有硬编码的阈值整理如下，建议在积累数据后进行回测验证：

| 指标 | 当前阈值 | 建议回测方法 |
|------|---------|------------|
| 封板率-强 | ≥ 80% | 统计封板率>80%后次日涨停溢价中位数 |
| 封板率-弱 | < 55% | 统计封板率<55%后次日涨停溢价中位数 |
| 涨停数-强 | ≥ 60 | 检查涨停>60的日子的前后行情特征 |
| 涨停数-弱 | < 20 | 2022-2023熊市期间涨停<20的占比 |
| 溢价率-好 | ≥ +2% | 检查溢价>2%时打板后的收益率分布 |
| 溢价率-差 | < -2% | 检查溢价<-2%时打板后的亏损率分布 |
| 高度断裂 | 前日-今日 ≥ 2 且前日 ≥ 4 | 检查高度断裂后3天的市场走势 |
| 情绪-冰点 | 封板<55%+涨停<30+高度≤3 | 回测冰点后5个交易日的反弹概率 |
| 情绪-高潮 | 封板≥75%+涨停≥50+高度≥5 | 回测高潮后的回调深度 |
