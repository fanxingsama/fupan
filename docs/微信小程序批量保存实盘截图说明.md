# 微信小程序批量保存实盘截图说明

这个仓库里新增了一个通用脚本：

`scripts/wxmp_image_downloader.py`

它不能只靠小程序分享口令直接抓数据，通常还需要你先拿到小程序实际请求的接口地址、请求头和用户标识。拿到这些之后，就可以自动翻页并批量下载某个人发过的实盘截图。

## 最稳的操作方式

1. 在电脑上打开微信，并进入目标小程序。
2. 用抓包工具观察网络请求，推荐：
   - Fiddler Classic
   - Charles
   - mitmproxy
3. 在小程序里点进目标用户主页，翻一下他的历史内容。
4. 在抓包工具里找“列表接口”：
   - 返回值通常是 JSON
   - 里面能看到帖子列表、图片地址、用户 ID、分页参数
5. 把下面这些信息填进 `scripts/wxmp_downloader_config.example.json`：
   - `api.url`：列表接口地址
   - `api.method`：GET 或 POST
   - `api.headers`：认证头、token、cookie
   - `api.json_body.userId`：目标用户 ID
   - `api.json_body.pageSize`：每页数量
   - `api.paging.page_field`：页码字段名，常见是 `page`

## 运行方式

```powershell
python scripts/wxmp_image_downloader.py --config scripts/wxmp_downloader_config.example.json
```

下载结果会保存到：

`downloads/<task_name>/`

同时会生成一个 `manifest.json`，里面会记录总共提取到了多少张图片、翻了多少页。

## 常见问题

### 1. 只有分享口令，脚本能直接抓吗？

通常不行。分享口令只是小程序内的入口，不等于真实接口地址。

### 2. 找不到用户 ID 怎么办？

点进目标用户主页后，抓包里通常能看到：

- `userId`
- `uid`
- `authorId`
- `playerId`

这类字段之一。

### 3. 下载时报 401 或 403

说明接口做了鉴权。需要把抓包里的以下内容补进配置：

- `Authorization`
- `Cookie`
- `X-Token`
- `Referer`

### 4. 图片地址不是直接文件链接

有些接口返回的是文件 ID 或媒体对象，不是最终图片 URL。这种情况下需要继续抓“详情接口”或“媒体换链接口”。
